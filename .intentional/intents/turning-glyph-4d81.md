The findings screen says which of the two empty states it is in. While the run
it draws is in flight, the body names the repository being observed under a
turning glyph and the status line carries the same reading, so a wait is never
silent and is never read as a repository with nothing to report. The queue's
scroll note is withheld where the window holds the whole of it: a line stating
that nothing is above and nothing is below reports only that the screen is
showing what is on it.
