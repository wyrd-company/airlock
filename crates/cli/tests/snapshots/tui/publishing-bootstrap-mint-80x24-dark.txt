PUBLISHING BOOTSTRAP                                                            
Most registries will not accept a trusted publisher for a package that has never
been published. A token exists only to produce that first release, and that     
token is the thing the policy is trying to eliminate. First publication is a    
distinct, human-supervised, credentialed event; steady state is credential-free.
                                                                                
package       sample-package · crates.io                                        
observed      0s ago · press o to re-observe now                                
publication   `sample-package` is not on crates.io                              
                                                                                
THE FIVE STEPS                                                                  
▶ 1. Mint a registry token — live                                               
     mint a token on crates.io scoped to publishing `sample-package`. Expiry:   
     seven days — long enough that the first release cannot outlive it, short   
     enough that an abandoned ceremony expires on its own.                      
▶ 2. Set it as a repository secret — live                                       
     supply the token's value; airlock writes it to `CARGO_REGISTRY_TOKEN`      
     after you confirm that named write                                         
· 3. Wait for a release to run and publish — blocked                            
     step 2 — the release has no credential to publish with yet
