PUBLISHING BOOTSTRAP                                                            
Most registries will not accept a trusted publisher for a package that has never
been published. A token exists only to produce that first release, and that     
token is the thing the policy is trying to eliminate. First publication is a    
distinct, human-supervised, credentialed event; steady state is credential-free.
