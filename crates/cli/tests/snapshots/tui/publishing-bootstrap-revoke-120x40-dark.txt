PUBLISHING BOOTSTRAP                                                                                                    
Most registries will not accept a trusted publisher for a package that has never been published. A token exists only to 
produce that first release, and that token is the thing the policy is trying to eliminate. First publication is a       
distinct, human-supervised, credentialed event; steady state is credential-free.

THE FIVE STEPS                                                                                                          
? 1. Mint a registry token — unobservable                                                                               
     the repository holds `CARGO_REGISTRY_TOKEN`, so a token was minted; the token itself is the registry's and airlock 
     never sees it. Its expiry is not observable either, and airlock does not guess one.                                
● 2. Set it as a repository secret — done                                                                               
     `CARGO_REGISTRY_TOKEN` was re-observed on the repository just now                                                  
● 3. Wait for a release to run and publish — done                                                                       
     `sample-package` is on crates.io                                                                                   
? 4. Configure the trusted publisher — unobservable                                                                     
     configure the trusted publisher for `sample-package` on crates.io, before revoking. Whether you have is not a fact 
     airlock can read, so it neither claims nor denies it: crates.io gates the configuration read on crate ownership,   
     which airlock does not have. The public `trustpub_only` bit is read instead: when true the crate refuses any       
     publish that did not come through trusted publishing.                                                              
▶ 5. Revoke the token and delete the secret — live                                                                      
     revoke the token on crates.io and delete `CARGO_REGISTRY_TOKEN`, once the trusted publisher is configured —        
     airlock cannot see whether it is. The bootstrap is not conformant while the credential exists.
